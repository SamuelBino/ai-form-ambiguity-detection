# AI-based Ambiguity Detection in Government Forms

**A system that automatically detects ambiguous questions in government forms, classifies them, assigns risk levels, and suggests simpler wording to improve accessibility and reduce errors.**

---

## 🚀 Overview

Government forms are often confusing, leading to errors, rejected applications, and user frustration—especially for first-time applicants or those in rural areas.  

This project leverages **AI and cloud technologies** to automatically:

- Detect ambiguous or unclear questions
- Classify them into types: **linguistic, conditional, missing context**
- Assign a **risk level** for each question
- Suggest **simpler, user-friendly wording**  

The backend is built with **AWS serverless services** and integrates a **Large Language Model (LLM)** for advanced language comprehension and text processing, ensuring **scalability, reliability, and fast response times**.

---

## 💡 Features & USP

- **AI-powered analysis:** Goes beyond fixed rule-based templates to understand language nuances.
- **Ambiguity classification:** Categorizes unclear questions into types for better insight.
- **Risk assessment:** Highlights high-risk questions that are likely to confuse users.
- **Guided simplification:** Suggests clear, user-friendly wording to reduce mistakes.
- **Accessibility focus:** Helps citizens, particularly first-time and rural applicants, fill forms correctly.
- **Scalable cloud backend:** Uses serverless architecture for reliability and speed.

---

## 🛠️ Tech Stack

- **Backend:** AWS Lambda, API Gateway, DynamoDB  
- **AI/ML:** Large Language Model (LLM) for natural language understanding  
- **Other Tools:** Serverless framework for deployment, Postman for API testing  

---

## 🎯 Benefits

- Reduces errors and rejected forms  
- Improves accessibility to public services  
- Provides actionable guidance for government agencies to improve form clarity  
- Enhances user experience, especially for first-time applicants  

---

## 🔗 Usage

1. Deploy backend services on AWS using Serverless Framework.  
2. Integrate the LLM for text analysis.  
3. Submit government form questions via the API.  
4. Receive ambiguity classification, risk level, and suggested rewording.
